**Define DONE before starting (acceptance criteria).**

State, concretely and verifiably:
- **What DONE looks like** — the observable end state, not an activity.
- **How each criterion is verified** — the exact check (test to run, endpoint to
  hit, query to observe, screen to load). A criterion you cannot verify is not a
  criterion.
- **Success metrics**, if any.

A task is complete (§12) ONLY when: every criterion is met; tests pass; it is
verified against the real system; nothing rests on a mocked assumption;
documentation is updated; and it is production-ready or clearly labelled otherwise.
