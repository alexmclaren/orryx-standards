## Conventions

- **Mermaid-first.** No Graphviz/C4 sidecar sources. Mermaid covers flowchart, sequence,
  state, ER, C4, mindmap, gitGraph. SVG export (when a doc needs embedding elsewhere):
  `npx -y @mermaid-js/mermaid-cli -i <file>.md -o out/` — deliberately not a CI step until
  something actually consumes SVGs.
- **Obsidian access:** this folder is junctioned into the vault at
  `D:\Vault\main\30-Projects\orryx-standards-architecture` (the 30-Projects layer this was
  reserved for). Repo is canonical; vault is the viewer. LEAK GUARD: nothing personal in here.
- **Gap colouring** in diagrams: red = broken/missing, orange = human choke point,
  green = healthy autonomous path, dashed red = dead end (output nobody consumes).
